Components

Metrics and dimensions pulled from the CJA semantic layer, curated with business context here.

Context is shared across data views for standard dimensions and metrics, such as Day, Month, Week, Visits and Visitors. These keep one entry, and each data view adds its reference to it, so you curate them once, and they appear under every data view that uses them in the data view filter. Custom components are kept separately for each data view, because a metric such as Orders can mean different things in different data views.
