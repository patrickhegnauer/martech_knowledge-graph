One row per step of the journey, in order. Each stage is measured by a component you already have. Set a filter value when several stages share one component (e.g. the same page-name dimension, different page paths), and optionally entry criteria to spell out exactly what counts as reaching this stage (e.g. which page, or "at least 2 items in cart").
