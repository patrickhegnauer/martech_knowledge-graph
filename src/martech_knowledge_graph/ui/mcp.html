Built — run it from a terminal. There's no one-click "start" button on this page yet (that's a deliberate next step, not a gap); until then, the CLI is the real, working way to run it.

Run it

martech-knowledge-graph mcp

Reads the same --data-dir and demo/org mode martech-knowledge-graph serve uses (shares its .mkg-mode file) — switching workspaces in the browser is reflected on the MCP server's very next tool call, no restart needed. By default it prints and serves at http://127.0.0.1:8931/mcp — point any MCP-compatible client (Claude, an agent framework, etc.) at that URL.

Tool set

Single-doorway principle: one query interface, not multiple competing tools.

ToolPurpose
run_sparql Runs a read-only SPARQL query (SELECT / ASK / CONSTRUCT / DESCRIBE) against the currently active workspace's graph. Write forms (INSERT/DELETE) aren't filtered out — they simply fail to parse against rdflib's read-only query grammar, so there's no separate check that could have a gap in it.
get_ontology_schema Returns every class and property in the ontology — name, comment, and (for properties) domain/range — extracted live from martech-ontology.ttl, so it can't drift out of sync with the real schema. Meant to be called before run_sparql by a caller that doesn't already know the graph's shape.

Security posture

No authentication yet — the server binds to 127.0.0.1 only by default, matching every other part of this tool's local-first trust model (same as martech-knowledge-graph serve). Reachable only from the machine it runs on unless you deliberately pass --host to change that.
