Skills

A skill file tells an AI agent how to use this MCP connection well: what the graph means, example queries, what to watch out for. The SKILL.md in this repo documents the bundled demo workspace; the button below drafts one grounded in your own data instead: it pulls the live ontology schema and runs the example queries against your graph right now, so the draft shows real row counts, not guesses. It's a starting point. Finish the wording (and the "Things to get right" section) by hand or hand it to your own LLM; there's no AI built into this app to do that part for you. See the MCP page for how to actually connect an agent.
